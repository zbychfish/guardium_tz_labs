    GIM

    GIM minimum installation and de-installation

    1. Because this is a freshly installed environment, the raptor machine must be rebooted. Once the reboot is complete, sign in to the system again. 
      shutdown -r now
    2. On raptor using ssh, jump to directory /opt/guardium_tz_bootcamp_automation/upload/source_files/agents/shell/ 
      cd /opt/guardium_tz_bootcamp_automation/upload/source_files/agents/shell/
    3. Set all files as a executable 
      chmod +x *.sh
    4. Execute GIM client installer without parameters to see available installation parameters 
      ./guard-bundle-GIM-12.2.1.1_r123268_v12_x_1-rhel-9-linux-x86_64.gim.sh
    5. Install GIM client in the listener mode 
      ./guard-bundle-GIM-12.2.1.1_r123268_v12_x_1-rhel-9-linux-x86_64.gim.sh -- --dir /opt/guardium --tapip <raptor_ip>
    6. Open port 8445 on raptor and check socket availability of this port. 
      1
2
3
4
5
      firewall-cmd --zone=public --add-port=8445/tcp

firewall-cmd --reload

nc -zv <raptor_ip> 8445

    7. You can also list GIM client processes on raptor machine and notice that it is listening on port 8445. 

      ps -ef | grep gim

    8. On cm, using UI check the absence of GIM clients currently registered to (GIM Process Monitor form).

    9. Then register installed gim_client using GIM Remote Activation form. Put the raptor IP address and listener default port (8445) and press Submit button. The pop-up window should confim that gim client has been successfully registered to GIM server.

    10. Check again GIM Process Monitor view and notice that raptor GIM client is registered.

    11. In most cases, GIM client will not be installed in listener mode; instead, the connection to the GIM server will be configured during installation. To proceed, first uninstall the GIM client. Run the uninstallation command on the raptor machine. 

      /opt/guardium/modules/GIM/current/uninstall.pl

    12. Check GIM Process Monitor and notice that list of GIM clients is empty.

    13. Then install GIM client again on raptor with automatic registration to GIM server located on your cm. 

      1
2
3
      cd /opt/guardium_tz_bootcamp_automation/upload/source_files/agents/shell/

./guard-bundle-GIM-12.2.1.1_r123268_v12_x_1-rhel-9-linux-x86_64.gim.sh -- --dir /opt/guardium --tapip <raptor_ip> --sqlguardip <cm_ip>

    14. Switch to cm UI (your GIM server) and check view – GIM Processes Monitor to confirm that GIM client has been registered successfully again.

    GIM modules upload

    1. Now we need to download GIM modules to GIM server. They are unpacked on ceratops. On ceratops machine (RDP connection) open Edge browser and ignore browser personalization (remember to open RDP tunnel)

    2. Login to cm UI from ceratops (you should have cm bookmark in favourites inside Guardium group) then open Upload Modules view

    3. Click plus button to upload the modules c:\bootcamp\gim directory. Select the first file. Once selected, click Upload.

      Important

      Do not refresh the window. Wait patiently till the import confirmation will appear. When it does, click Import Now and wait until you see a message confirming that the import completed successfully.

      1. Import module

    4. Confirm that GIM module has been uploaded

    5. Repeat steps 2-4 for all files in c:\bootcamp\gim directory!

      Info

      Your GIM modules list can be different than presented on screenshot.

    GIM upgrade

    1. Go to Set up by Client in cm UI and select your raptor GIM client. Switch to next section by pressing Next button

    2. Expand list of modules and select from the list BUNDLE-GIM module. Notice that the installed version of GIM client is for Guardium release 12.1 and the latest available GIM client module on GIM Server is released for version 12.2.2 (just uploaded 12.2.2.0_r123489_1). That is why the Upgrade action is displayed on view. Press Next and then Install button because we do not need modify any parameters for GIM client this time and we can start upgrade immediately.

    3. Press OK button to send upgrade request.

    4. Select Show Status link to monitor upgrade progress. After a while all GIM Bundle modules should be successfully updated.

    5. Go to GIM Processes Monitor view again and check that new release of GIM client is running on raptor

    Module configuration

    1. Go to Set up by Client in cm GUI and select your raptor GIM client again and press Next.

    2. Notice that GIM client is updated to the latest release on GIM server and parameter updates are possible only. Press Next button.

    3. Select from parameters list GIM_DEBUG and change value to 1. Then push request using Install and OK buttons.

    4. In Status pop-up window notice that only some modules requires update.

    5. Refresh view, to get confirmation that changes have been successfully deployed.

    6. Login to raptor and list installed GIM client modules using configurator.sh tool 

      /opt/guardium/modules/UTILS/current/files/bin/configurator.sh --list

    7. Check that GIM_DEBUG parameter in GIM module is set to 1. 

      /opt/guardium/modules/UTILS/current/files/bin/configurator.sh --get GIM

    8. Change GIM_DEBUG value to 0 and confirm change (this time from command line instead from GIM server). 

      1
2
3
      /opt/guardium/modules/UTILS/current/files/bin/configurator.sh --set GIM_DEBUG 0

/opt/guardium/modules/UTILS/current/files/bin/configurator.sh --get GIM

    9. Uninstall GIM client. 

      /opt/guardium/modules/GIM/current/uninstall.pl

    GIM module management with API (optional)

    1. Go to gim installers directory on raptor. 

      cd /opt/guardium_tz_bootcamp_automation/upload/source_files/agents/shell

    2. Install again GIM client version 12.2.1. 

      ./guard-bundle-GIM-12.2.1.1_r123268_v12_x_1-rhel-9-linux-x86_64.gim.sh -- --dir /opt/guardium --tapip <raptor_ip> --sqlguardip <cm_ip>

    3. In cm cli session list the installed modules on raptor machine. All grdapi commands are run from cm cli session. 

      grdapi gim_list_client_modules clientIP=<raptor_ip>

    4. Then list of bundles available on GIM server (windows modules are filtered out because client is linux based). 

      grdapi gim_list_bundles

    5. Assign to GIM client the update of GIM-BUNDLE to the latest version and check module list.

      1
2
3
      grdapi gim_assign_latest_bundle_or_module_to_client module=BUNDLE-GIM clientIP=<raptor_ip>

grdapi gim_list_client_modules clientIP=<raptor_ip>

      Notice

      Notice that GIM client 12.2 version has been set as scheduled but schedule time is not set yet.

    6. Set update schedule. 

      grdapi gim_schedule_install date=now clientIP=<raptor_ip>

    7. Monitor the upgrade process. 

      grdapi gim_list_client_modules clientIP=<raptor_ip>

      Note

      After few minutes the command will provide the output change. It should confirm that GIM client has been updated to the latest version available on GIM server.

    8. Now set GIM_DEBUG to 1. 

      grdapi gim_update_client_params paramName=GIM_DEBUG paramValue=1 clientIP=<raptor_ip>

    9. You should notice that change is notified but is not scheduled. 

      grdapi gim_list_client_modules clientIP=<raptor_ip>

    10. Schedule update. 

      grdapi gim_schedule_install date=now clientIP=<raptor_ip>

    11. Then monitor GIM client state to confirm that schedule is started and finally applied. 

      grdapi gim_list_client_modules clientIP=<raptor_ip>

    12. Finally uninstall GIM client from raptor. Monitor list of modules on raptor and confirm uninstallation process. 

      grdapi gim_uninstall_module module=BUNDLE-GIM clientIP=<raptor_ip>

grdapi gim_schedule_uninstall date=now clientIP=<raptor_ip>

grdapi gim_list_client_modules clientIP=<raptor_ip>

    13. After a while list of modules assigned to GIM client should be empty. 

      grdapi gim_list_client_modules clientIP=<raptor_ip>

    14. The list of GIM clients registered to GIM server on cm should be empty as well 

      grdapi gim_list_registered_clients

    15. Because of GIM client issue during uninstallation from API, execute these commands on raptor to clean system 

      systemctl disable guard_gim

rm -f /etc/systemd/system/guard_gim.service

rm -rf /usr/local/guardium

rm -rf /var/log/guard
