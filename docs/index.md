# Guardium Data Protection Bootcamp Labs

Welcome to the **IBM Security Guardium Data Protection (GDP) Bootcamp** laboratory documentation. This portal provides comprehensive, step-by-step guides for all hands-on exercises designed for the IBM Technology Zone (TechZone) training environment.

---

## About the Lab Environment & Automation

These lab exercises reflect the exact procedures automated in the companion **`guardium_tz_bootcamp_automation`** project. The automation framework allows instructors and participants to provision, configure, and validate stages of the bootcamp automatically, while this documentation serves as the reference walkthrough for manual execution and deep-dive learning.

---

## Lab Curriculum Overview

The bootcamp hands-on program covers core operational, configuration, and security capabilities of Guardium Data Protection:

0. **Environment Access & Connectivity (Lab 00)**
   - Gathering deployment details from IBM Technology Zone.
   - Establishing secure SSH and RDP management tunnels via the **raptor** bastion host.
   - Accessing Central Manager and Collector web user interfaces.

1. **Appliances Setup & Central Management (Lab 01)**
   - Initial appliance registration to Central Manager (CM).
   - Patch distribution, system verification, and health checks.
   - System backup and configuration archive setup.

2. **GIM Management**
   - Guardium Installation Manager (GIM) client discovery, setup, and configuration.
